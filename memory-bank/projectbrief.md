# Project Brief: SalesAI - Sales Call Analyzer

## Project Overview
SalesAI is a comprehensive sales call analysis platform that transcribes sales conversations and provides AI-powered insights to help sales teams improve their performance.

## Core Requirements

### Primary Goals
1. **Transcribe Sales Calls** - Convert audio recordings to accurate text with speaker diarization
2. **Identify Speakers** - Automatically classify speakers as Seller or Buyer
3. **Analyze Conversations** - Provide deep insights using AI Sales Coach
4. **Improve Sales Performance** - Offer actionable feedback and better response suggestions

### Key Features
1. **Audio Upload & Transcription**
   - Support for various audio formats
   - Real-time progress tracking
   - Speaker diarization with role assignment

2. **AI Sales Coach Analysis**
   - MEDDIC scoring (Metrics, Economic Buyer, Decision Criteria, Decision Process, Identify Pain, Champion)
   - BANT qualification (Budget, Authority, Need, Timeline)
   - Objection detection and categorization
   - Talk-to-listen ratio analysis
   - Deal risk assessment

3. **Objection Handling Focus**
   - Identify objection type (Price, Trust, Timing, Authority, Need, Competition)
   - Show buyer's original statement
   - Show seller's response
   - Provide better response suggestions with explanations

4. **Coaching & Improvement**
   - AI-generated coaching suggestions
   - Better response alternatives
   - Recommended next steps
   - Performance scoring

## Target Users
- Sales Representatives
- Sales Managers
- Sales Coaches
- Revenue Operations Teams

## Success Metrics
- Accurate transcription with correct speaker attribution
- Meaningful objection detection and categorization
- Actionable improvement suggestions
- User-friendly interface with clear insights
