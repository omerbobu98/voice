# Product Context: SalesAI

## Why This Project Exists

### The Problem
Sales teams struggle to improve their performance because:
1. **No visibility into calls** - Managers can't review every call
2. **Subjective feedback** - Coaching is often based on gut feeling, not data
3. **Missed learning opportunities** - Objections and mistakes go unnoticed
4. **No scalable coaching** - Senior reps can't mentor everyone

### The Solution
SalesAI provides automated, AI-powered analysis of every sales call, giving teams:
- Objective performance metrics
- Specific improvement suggestions
- Better response alternatives for objections
- Standardized methodology scoring (MEDDIC, BANT)

## How It Should Work

### User Flow
1. **Upload** - User uploads a sales call recording
2. **Transcribe** - System transcribes with speaker identification
3. **Review** - User sees transcription with Seller/Buyer labels
4. **Analyze** - User clicks "Analyze Call" for deep AI analysis
5. **Learn** - User reviews objections, suggestions, and improvements

### Key Interactions
- **Drag & drop** audio file upload
- **Real-time progress** during processing
- **Clear separation** between transcription and analysis phases
- **Visual hierarchy** for objections (most important feature)

## User Experience Goals

### Clarity
- Every insight should be immediately actionable
- Objections should show: what was said → how it was handled → how to do better
- Scores should have clear meaning and benchmarks

### Speed
- Transcription should show real-time progress
- Analysis should run separately (not blocking transcription view)
- Results should load progressively

### Value
- Every analysis should teach something new
- Better responses should be specific, not generic
- Coaching suggestions should include example scripts

## Key Differentiators
1. **Strong objection focus** - Not just detecting, but improving responses
2. **Dual methodology scoring** - Both MEDDIC and BANT
3. **Specific improvements** - Actual scripts, not vague advice
4. **Beautiful UI** - Modern, dark theme, professional appearance
