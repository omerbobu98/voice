# 🎯 פרומפט לשיחה הבאה - שיפור חוויית משתמש במובייל

## המשימה
אני רוצה לשפר את חוויית המשתמש (UX) באפליקציה כשמשתמשים בה מהטלפון הנייד. המטרה היא להפוך את השימוש לאינטואיטיבי, נוח וברור ככל האפשר.

## מה לבדוק - רשימה מפורטת

### 1. 📱 Layout & Responsive Design
- [ ] האם כל הדפים מותאמים למסך קטן?
- [ ] האם יש אלמנטים שנחתכים או יוצאים מהמסך?
- [ ] האם ה-navigation נוח במובייל? (hamburger menu, bottom nav, etc.)
- [ ] האם יש מספיק padding/margin בין אלמנטים?
- [ ] האם הטקסט קריא בגודל מסך קטן?

### 2. 👆 Touch Targets
- [ ] האם כל הכפתורים מספיק גדולים (מינימום 44x44px)?
- [ ] האם יש מספיק מרווח בין כפתורים סמוכים?
- [ ] האם קל ללחוץ על לינקים ופעולות?
- [ ] האם יש feedback ויזואלי ללחיצה (active states)?

### 3. 📝 Forms & Inputs
- [ ] האם ה-input fields מספיק גדולים?
- [ ] האם המקלדת לא מסתירה את השדות?
- [ ] האם יש auto-focus נכון?
- [ ] האם יש keyboard type נכון (email, phone, number)?
- [ ] האם הטופס גוללת בצורה נוחה?

### 4. 🎤 Live Call / Recording
- [ ] האם ממשק ההקלטה נוח במובייל?
- [ ] האם הכפתורים זמינים ביד אחת?
- [ ] האם יש visual feedback להקלטה פעילה?
- [ ] האם הטרנסקריפט קריא ונוח לגלילה?
- [ ] האם ה-coaching tips לא מפריעים?

### 5. 📊 Analysis & Results
- [ ] האם התוצאות מוצגות בצורה ברורה במובייל?
- [ ] האם הגרפים מותאמים למסך קטן?
- [ ] האם הטקסט של האנליזה קריא?
- [ ] האם ניתן לנווט בין חלקי האנליזה בקלות?

### 6. 🔊 Audio Player
- [ ] האם נגן האודיו נוח לשימוש?
- [ ] האם הכפתורים מספיק גדולים?
- [ ] האם יש אפשרות לדלג קדימה/אחורה בקלות?
- [ ] האם ה-timestamp clickable ועובד?

### 7. 📤 Upload Flow
- [ ] האם קל להעלות קובץ מהטלפון?
- [ ] האם יש תמיכה בצילום ישיר?
- [ ] האם יש progress indicator ברור?
- [ ] האם הודעות השגיאה ברורות?

### 8. 🎨 Visual Hierarchy
- [ ] האם ברור מה הפעולה הראשית בכל מסך?
- [ ] האם יש היררכיה ויזואלית נכונה?
- [ ] האם הצבעים והניגודיות מספיקים?
- [ ] האם יש מספיק white space?

### 9. ⚡ Performance
- [ ] האם הדפים נטענים מהר?
- [ ] האם יש loading states?
- [ ] האם התמונות אופטימיזציות?
- [ ] האם אין lag בגלילה?

### 10. 🔄 Gestures & Interactions
- [ ] האם יש תמיכה בswipe?
- [ ] האם pull-to-refresh עובד?
- [ ] האם יש haptic feedback?
- [ ] האם הגלילה חלקה?

## דפים לבדוק
1. `/` - Landing Page
2. `/login` - Login Page
3. `/register` - Register Page
4. `/app` - Main Dashboard (Upload)
5. `/app/history` - Call History
6. `/app/call/:id` - Call Analysis View
7. `/app/live` - Live Call Coach
8. `/app/ai-agent` - AI Agent Page

## כלים לשימוש
- Chrome DevTools (Device Mode)
- Real device testing
- Lighthouse Mobile Audit
- Playwright browser testing

## מה לתקן קודם (Priority)
1. **Critical**: דברים שמונעים שימוש
2. **High**: דברים שמקשים על שימוש
3. **Medium**: דברים שמשפרים חוויה
4. **Low**: Nice to have

## הערות
- כל השינויים צריכים לעבוד גם ב-desktop
- לשמור על עקביות עיצובית
- לבדוק גם landscape mode
- לבדוק בגדלי מסך שונים (iPhone SE עד iPhone Pro Max)
